# Bug Fix: 工具调用默认折叠

## 问题描述

- 日期: 2026-08-31
- 严重程度: Medium
- 影响范围: Web 会话区域的工具调用展示
- 连续工具调用在执行过程中逐项展开，完成后仍占用大块会话空间。

## 根因分析

- 问题位置: `packages/dsh-client/src/client/RemoteConversation.tsx`
- 工具节点在“运行中且没有结果”时把 `open` 初始化为 `true`，之后结果到达不会重置该本地状态，因此连续工具调用会保持展开。

## 修复方案

- 工具节点无论运行中、已完成或缺少结果，均默认折叠为 24px 单行状态。
- 保留整行点击和键盘操作，用户可随时展开调用与结果，再次点击收起。
- 将初始展开与状态文案提取为可测试的展示策略，避免后续重新引入自动展开。

## 验证步骤

1. ✅ 单元测试覆盖运行中、已完成和无结果三种状态均默认折叠。
2. ✅ 执行客户端相关测试。
3. ✅ 执行类型检查、构建和完整测试套件。

## 相关测试

- `packages/dsh-client/tests/conversation-model.spec.ts`

## 设计建议

- 工具详情属于按需信息，默认保持紧凑；实时执行状态继续通过单行“运行中”文案表达。
